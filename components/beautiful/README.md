# Beautiful UI in Forma

Task rows and source sync status adapt the list layout, circular status marks and compact status pills from [Beautiful UI TaskRows](https://github.com/slev12397/beautiful-ui/blob/44a274e598395ab61e7c96c26fda2758780253b7/components/primitives/TaskRows.tsx).

Upstream revision: `44a274e598395ab61e7c96c26fda2758780253b7`. MIT notice is retained in LICENSE.

Forma uses its existing CSS tokens and Morphicons. No upstream demo data, timed status sequence, automatic completion, paid icons or Tailwind foundation is included. Task actions and source coverage remain connected to Forma's existing data.
